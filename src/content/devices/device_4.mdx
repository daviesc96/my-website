This project began with a simple idea: treat an input signal as data, then turn the data back into music. Instead of composing notes directly, the patch listens for structure in the spectrum and uses that structure to trigger or reshape sound.

<Photo src="device_4/analog-03.jpg" caption="The analyzer view, showing the patch as a system for reading and reinterpreting frequency content." />

The interesting part is that it never really sounds like the original source. The signal is filtered through analysis, peak selection, and granular resynthesis, which means the output becomes a derived instrument rather than a direct copy. That makes it ideal for sonifying environmental recordings, speech, or feedback loops.

## Technical Breakdown

- **FFT analysis** with variable bin resolution (256–2048 bins)
- **Peak detection** to find dominant frequencies
- **Spectral tracking** of frequency evolution over time
- **Granular playback** triggered by spectral features
- **Re-synthesis** using detected frequencies as pitch guides

### The Pipeline

Input audio → FFT analysis → Peak finding → Score selection from pitch set → Granular synthesis triggered on peaks → Output

## Development Notes

Early iterations used simple peak-following. The breakthrough was:

1. **Multi-resolution FFT** (different analysis windows for different purposes)
2. **Harmonic grouping** (associate harmonically-related bins)
3. **Temporal smoothing** to prevent jittery behavior
4. **Visualization** of the analysis pipeline so you can see what it's doing

## Use Cases

- Transform spoken word into pitched material
- Create drum sounds from pitched input
- Analyze ambient recordings and create variations
- Real-time data sonification (sensor inputs, network traffic, etc.)

## Surprising Results

The most interesting sounds came from feeding the device back into itself—running its output through its input. Creates strange recursive timbres and unexpected rhythmic patterns.

## Next Steps

Currently exploring better harmonic constraint systems to keep output more musical when fed arbitrary input.
