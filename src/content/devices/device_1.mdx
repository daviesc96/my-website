This device was built around the idea that musical variation can emerge from a very small set of rules.

<Photo src="quartus_aron.jpg" caption="The machine in its default state, with each voice still visible as a separate rhythmic lane." />

The underlying structure is deliberately modular: nested loops, pacing offsets, and independent probability engines all work together to create a patch that feels both controlled and alive. The goal was not just to generate patterns, but to make those patterns behave like a live ensemble.

<Gallery photos={["kit_blur.jpg", "hans_synths.jpg"]} />

The interface gives quick access to the decisions that matter most: how often a cell changes, how far it drifts from the base tempo, and how much motion is allowed before the system collapses back into order. That balance is what makes it feel expressive rather than random.

## Design & Architecture

The core system uses nested loop hierarchies with independent probability engines for each voice. Each pattern layer can:

- **Randomly select from scale tones** avoiding obvious dissonance
- **Offset timing** for organic swing and feel
- **Modulate density** based on feedback from previous patterns
- **Distribute across stereo space** using panning envelopes

### Key Features

- 4-8 simultaneous polyrhythmic voices
- Real-time parameter tweaking via sliders and dials
- MIDI input for external control integration
- Harmonic constraint system to maintain musicality
- Visual feedback with LED indicators per voice

## Development Story

Started with a simple `counter~` + `choose` setup in 2022. Over iterations, I added:
- Harmonic analysis to avoid discordant intervals
- Feedback systems where outputs influence future decisions
- Dynamic compression to prevent surprise volume spikes
- A visual control interface for intuitive tweaking
