This delay network was built around one question: what happens when each echo can influence the others? The result is a system that feels less like a fixed effect and more like a small acoustic world with its own logic.

<Photo src="device_3/analog-01.jpg" caption="The control surface for a feedback matrix that can turn a single input into a dense, shifting web of repeats." />

The patch is intentionally unstable in a musical way. A tap is never just a delay—it becomes a trigger, a counterpoint, and sometimes a feedback source for the rest of the network. That makes it surprisingly good for ambient gestures, rhythmic erosion, and dense textural layering.

<Gallery photos={["device_3/analog-01.jpg", "device_3/analog-02.jpg"]} />

## How It Works

The device features:

- **8 independent delay lines** with variable tap times
- **Cross-feedback matrix** where each tap can send to others
- **Envelope followers** on each channel
- **Modulation of delay times** via LFOs and external CV
- **Tone stacking filters** per tap

### Signal Flow

Input → Envelope follower → Delay matrix → Cross-feedback mixing → Output compression → Main out

## Build Process

Started as a proof-of-concept using `groove~` and `record~`. Key additions:

1. **Resonant filter banks** per delay line to shape tone
2. **Probabilistic tap creation** (randomly enable/disable taps)
3. **Tempo sync** via external clock (MIDI beat clock)
4. **Visual tap position display** showing audio flowing through the network

## Sound & Application

Great for creating ethereal, decaying textures. The unpredictability of the feedback network means every performance is different, even with identical settings.

## Key Insight

Discovered that limit-ing feedback before it re-enters the delay network is crucial—otherwise it tends toward self-oscillation. The Goldilocks zone between chaos and musicality was hard-won.
